# Theses not written in English (and bilingual theses)

Read this whenever the thesis, the supporting documents, or the student's messages are in a language other than English, or the thesis mixes languages.

## 1. Which language to write the report in

Default: **the language the student is writing to you in.** A student who asks in Malay about an English thesis gets a Malay report; a student who asks in English about a Malay thesis gets an English report. If the student asks for a specific language, use that.

If you can't tell (e.g. the request is only an attached file), use the thesis's main language and offer the other in one line.

Whatever the report language:
- **Quote the thesis in its original language**, so the student can find the passage. Add a short translation in brackets only if the report language differs and the meaning matters.
- Keep technical terms in the form the student's field uses in that language. Where a field commonly uses the English term (e.g. many Malay-medium theses keep "SEM", "Cronbach's alpha", "purposive sampling"), don't force a translation.
- Keep the report's structure and status labels consistent. Translate headings and labels into the report language (e.g. Kritikal / Utama / Kecil; Ditangani / Sebahagian / Belum ditangani), and use the same terms throughout.

## 2. Judging the writing

Judge the language by **the academic conventions of the language the thesis is written in**, not by English norms. Formal academic Malay (laras bahasa akademik), Indonesian (bahasa Indonesia baku/EYD), French, Arabic or Chinese academic prose each have their own expectations for register, sentence structure, terminology and citation phrasing.

- Comment on clarity, register, consistency of terminology and correctness by those standards — for Malay, for example: consistent use of standard spelling (DBP conventions), appropriate formal register rather than conversational forms, consistent rendering of borrowed terms, and avoiding unnecessary code-switching into English mid-sentence where the university expects formal Malay.
- Don't treat structures that are normal in that language as errors just because English would phrase them differently.
- If your command of a language's academic conventions is limited, say so once and keep language feedback to clear-cut issues (inconsistency, sentences whose meaning is unclear), suggesting the student use their university's language editing service for a full check.
- As with English, separate language problems that obscure meaning (real issues) from stylistic polish (minor).

The rest of the assessment — argument, method, alignment, evidence — works the same in any language.

## 3. Bilingual requirements

Many universities require parts of the thesis in two languages (common in Malaysia: Abstrak in Malay and Abstract in English; also in Indonesia, Quebec, parts of the Middle East and Europe). When a thesis has parallel versions:

- Check **both are present** if the university requires them (ask or check the guidelines if unsure).
- Check they **say the same thing**: same aims, methods, key findings and figures. Mismatches are common after late revisions — one version gets updated, the other doesn't. List any differences specifically (e.g. "Abstract reports n = 312; Abstrak reports n = 300").
- Check each is **well written in its own language**, not a word-for-word machine translation; and that keywords match.
- Titles in two languages should match in meaning too.

## 4. Sources and quotations in other languages

- Quotations translated by the student should say whose translation it is ("translated by the author") and, where the field expects it, give the original in a footnote.
- Check that the translation conveys the original correctly when you can read both; flag apparent mistranslations as *Please check*.
- Transliteration (e.g. of Arabic, Chinese, Russian names and titles) should follow one system consistently, and the same author's name should be spelled the same way throughout.
- Referencing styles have language-specific rules (e.g. APA asks for an English translation of non-English titles in square brackets). Check consistency with the style the university requires.

## 5. Fact-checking and searches

Search in the language most likely to find the original source: local-language sources for national laws, policies, statistics and institutions (e.g. official Malaysian government portals in Malay), and the original language of a quoted work. Report what you found in the report language.

## 6. University and examiner documents in other languages

Guidelines and examiner comments may be in a different language from the thesis (e.g. Malay faculty guidelines, English thesis, comments in both). Build the registers in the report language, but keep the examiner's key phrase in its original wording so the student can match it to the comment sheet.
